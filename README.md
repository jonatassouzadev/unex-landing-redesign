# UNEX Landing Redesign

Crie o redesign completo da landing page institucional da UNEX — Centro Universitário de Excelência, em português do Brasil. Comece pela Home, mas entregue a estrutura visual completa solicitada: header sticky com menu mobile e CTA, hero moderno, estatísticas, sobre, cursos, formas de ingresso, benefícios, depoimentos com carousel responsivo, unidades, notícias, CTA final, formulário de captação validado com feedback e footer. Interface institucional própria, sofisticada, limpa, altamente responsiva e orientada à conversão. Use imagens relevantes otimizadas, animações sutis, acessibilidade e SEO. Preserve os textos e seções especificados pelo usuário, usando conteúdo demonstrativo plausível onde faltarem dados. Não use Vercel.
